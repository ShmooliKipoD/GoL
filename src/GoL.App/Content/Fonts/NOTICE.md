# Bundled font

**monogram** (`monogram.ttf`) by datagoblin — a pixel font, drawn on a 16px em grid.

Commonly distributed as CC0 / public domain, **but that has not been verified for
this copy**, which was carried over from the QiLight project where the license was
likewise unverified and unbundled.

**Before distributing GoL:** obtain the license text from the font's official
release page and place it beside this file, or replace the font with one whose
license is confirmed. Tracked as an open item in `docs/DESIGN.md`.
